Thought Atlas Mobile

仮説の思考地図

Import

コピペで使えます。プロンプトを自分のAIに貼り、返ってきた文章をそのままここへ貼り付けます。

  1. プロンプトをコピー
  2. ChatGPT / Claude / Gemini に貼る
  3. AIの返答全文を下に貼り付ける
  4. 読み込んでTourを見る

1. AIに渡すプロンプト

このプロンプトをコピーして、普段使っているAIに貼ります。コピーが拒否された場合は本文が全選択されるので、そのまま手動コピーしてください。

2. AIの返答をコピペ

待機中

AIが返した文章を全文貼り付けてください。説明文が混ざっていても、Atlas JSON部分を自動で探します。

このアプリは診断ではありません。 読み込んだ内容を、見直せる仮説の地図として表示します。違和感は編集メモとして残せます。

Privacy

ローカル処理
  • このアプリはAI解析を行いません。
  • 貼り付けたAI返答やAtlasは外部サーバーへ送信しません。
  • 読み込んだAtlasと編集メモは、このブラウザのLocalStorageに保存されます。
  • AIへ素材を渡す部分は、ユーザー自身が使うAIサービスの管理下です。
